# Draconia preview pack

The separate debug preview downloads `rig-preview/draconia/pack.json` from the `preview/draconia-companion` branch when opened and when Refresh animations is tapped. Choose a named study, pause, and compare light/dark backgrounds. A validated offline copy is cached; the debug APK includes the same full dance as its fallback pack. The Book Spirit widget remains separate.

**Neutral — front**, **angle**, **side**, and **rear** show the arms-down default stance with the reshaped cloak sleeve and the wand hidden. **Dance without wand — front**, **side**, and **rear** show the complete eight-second, 24 fps [Four-bar club phrase](https://www.innerscene.com/tools/library/3d-parts/four-bar-club-phrase-dancing-3d-person-animated-86561105) from Innerscene, released under CC0. All 192 unique source frames are retained. The dance is retargeted to the new neutral-rest rig; the original wand dance and earlier studies remain labeled for comparison. The revised rig gives the jacket, cloak, and hair more clearance. The wand is a separate hidden prop, and its future pickup animation has not yet been created. **Reach and hair — front/rear** shows the new two-second manual hair-control and reach diagnostic. This is a diagnostic animation, not a finished performance or a guarantee of collision-free clothing. The Draconia model is not covered by the motion's CC0 license.

The updated app stores encoded images and decodes frames as they are played instead of keeping every bitmap in memory. Format 1 clips contain a unique lowercase ID, label, `frame_ms`, optional `fps`, and base64-encoded WebP frames. When `fps` is provided it takes precedence for accurate playback timing. There is no fixed clip, frame-count, pack-size, image-size or duration cap, though available device memory and storage still apply. The app validates an update before replacing its cached copy. Older preview APKs reject this longer pack and must be updated; refreshing alone cannot change the app's playback limits.

Render transparent frames from the Blender master, package them under this format, test playback, and commit the pack to this branch. Once the updated APK is installed, opening or refreshing the app fetches future pack changes without another reinstall. Changes to app code still require a new APK. The debug package uses the `.rigpreview` application ID and is separate from production.

**Experimental blink — front/angle** shows the revised blink study: the lid lowers over the painted whites and full-size irises, with a fuller closed lid and tapered corners. It remains a stylized, Blender-specific approximation and is separate from the neutral default.

**Reach clearance — front/rear** compares a refined two-second reach with smoother manually keyed hair clearance and the accepted blink. Some hair/cloak intersections remain; the correction applies to this motion and is not a collision solver. The earlier **Reach and hair** views remain available for comparison.

**Clothing fix — front/side/rear** plays all 192 frames of the eight-second dance with the jacket-side clearance, approved blink, and keyed hair adjustments. **Clothing fix — close-up** shows all 192 frames at a closer scale. The prior **Dance without wand** views remain for comparison. Some intersections remain; the hair correction is specific to this animation.
